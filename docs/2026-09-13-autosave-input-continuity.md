# 自动保存输入连续性修复

## 问题与设计
标题和“我的想法”使用原生输入控件。保存状态更新会改变回调引用并触发 DOM 观察器，重复发送相同配置；原生层每次重新设置编辑权限，可能干扰输入会话。
保持 1200ms 自动保存。配置相同时不向原生层重复发送；回调更新只更新引用。原生编辑权限仅在变化时设置。实际布局、外部文本和只读状态变化仍正常同步。

## 实现计划
1. 两类输入控件增加配置去重，失败后允许重试。
2. 原生层避免重复设置 editable/selectable。
3. 回归验证保存状态刷新不触发重复同步，以及布局变化仍正常同步；运行前端测试、lint、构建与 Rust 验证。

## 验证结果
- 原生输入桥接和卡片自动保存相关测试：17 项通过。
- 前端 lint 和生产构建通过；构建仍提示主包大于 500 kB。
- Rust 库测试：226 项通过，包含本机 macOS 原生代码编译。
- 尚未重新打包安装应用或进行真实中文输入法、豆包语音连续输入验收。
