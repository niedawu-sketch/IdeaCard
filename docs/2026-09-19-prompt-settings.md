# 提示词配置

## 设计

设置保留“模型 API 配置”，原“AI 概念助手”入口收进可展开的“提示词配置”，其下列出“AI 概念助手”和“标题生成”。沿用现有设置弹窗和视觉规则，每项独立编辑、保存和恢复默认；恢复默认先填入编辑框，点击保存后才生效。加载失败显示错误并允许重试，不使用默认值冒充已保存配置。

标题提示词只影响未来新建卡片，不触发旧卡片重新生成，不改变首次创建一次的约束。提示词为 1～8000 字符。标题仍要求单行、最多 40 字符；弹窗明确说明这项输出限制。原文传入、禁用联网、失败回退和并发编辑保护沿用现有行为。

## 实现计划

1. 在现有 app_settings 表中新增独立配置键，定义标题提示词默认值和校验；不变更数据库结构。
2. 新增读取与保存命令，标题生成读取当前已保存提示词。
3. 复用提示词编辑弹窗，增加菜单展开层级和标题配置入口，处理加载、保存失败和键盘操作。
4. 验证配置持久化、两个配置互不干扰、实际请求使用自定义提示词，以及菜单和弹窗操作；运行测试、构建并在开发环境检查。

## 验证结果

- Rust 测试 231 项通过，覆盖标题配置默认值、非法内容拒绝、独立保存、重新打开数据库回显和恢复默认。
- 前端测试 195 项通过，覆盖加载失败重试、禁止空提示词、保存失败保留编辑内容和恢复默认只修改草稿。
- 设置菜单端到端测试通过：展开层级、两个编辑入口、保存并重新打开、Esc 关闭、侧栏折叠后菜单不溢出。
- 前端构建与 ESLint 检查通过；1100×700 截图已检查。
- 开发版已自动加载改动，未更改用户现有提示词，也未调用真实模型消耗额度。

## 悬停交互调整

将原本向下缩进展开改成右侧浮层：悬停父项自动打开，连续移入二级菜单不关闭，离开区域收起。保留点击展开与键盘左右进入/返回。实施时只调整菜单结构与定位，复用既有编辑和保存逻辑，再通过浏览器验证悬停路径及子项点击。
