# IdeaCard 捕获入口布局调整设计

## 1. 问题

当前桌面端把“剪贴板”和“导入文件”放在来源筛选区域中。两者属于捕获动作，不是来源类型，因此会造成以下问题：

- 用户容易把操作入口误认为来源分类。
- 两个强调样式按钮打断来源列表的连续性。
- 左侧来源栏同时承担筛选和捕获两种职责，信息结构不清晰。

## 2. 设计结论

采用“顶部更多捕获菜单”方案：

- 来源栏只保留“全部来源”和五种来源分类。
- “快速记录”继续作为顶部工具栏中的主要操作。
- 在“快速记录”左侧增加加号图标按钮，名称为“更多捕获方式”。
- 点击加号后展示两个菜单项：“从剪贴板捕获”和“导入本地文件”。

该方案在不增加新功能的前提下，把筛选和捕获两种职责分开，同时避免在最小窗口宽度下挤压搜索框。

## 3. 界面结构

### 3.1 来源栏

来源栏按以下顺序展示：

1. 全部来源
2. 个人记录
3. 文档资料

来源栏不再展示剪贴板和文件导入按钮。

### 3.2 顶部工具栏

顶部工具栏从左到右保持以下结构：

1. 搜索框
2. 当前结果数量
3. 刷新按钮
4. 更多捕获方式按钮
5. 快速记录按钮

“更多捕获方式”使用加号图标，不显示常驻文字，通过悬停提示和无障碍名称说明用途。

### 3.3 捕获菜单

菜单锚定在加号按钮下方并右对齐，包含：

- 从剪贴板捕获
- 导入本地文件

菜单项使用对应图标和文字，整行可点击。菜单不展示来源分类，不增加截图入口；截图继续通过菜单栏和全局快捷键触发。

## 4. 交互规则

- 点击加号按钮切换菜单的展开和收起。
- 点击菜单外部或按 `Esc` 收起菜单。
- 点击“从剪贴板捕获”后收起菜单，并进入现有剪贴板确认流程。
- 点击“导入本地文件”后收起菜单，并打开现有系统文件选择器。
- 导入结果浮层与菜单分离并锚定在加号按钮区域；菜单收起后，逐文件结果仍可展示。
- 捕获确认框、加载状态和现有错误处理沿用原有流程，不改变业务行为。
- 打开快速记录或捕获确认框时，捕获菜单保持关闭。

## 5. 组件调整

- `InboxPage`：从来源栏移除两个捕获入口，把入口接入顶部工具栏。
- 新增轻量的 `CaptureMenu` 组件，负责菜单开关、键盘关闭和点击外部关闭。
- `FileImport`：允许由菜单项触发，同时保持导入中状态和逐文件结果展示。
- 样式：增加捕获菜单及菜单项样式，不改变三栏宽度和来源筛选样式。

组件只复用现有桌面服务，不新增后端命令、数据结构或权限。

## 6. 验收标准

1. 来源栏只出现“全部来源”和五种来源分类。
2. 顶部工具栏显示加号图标和“快速记录”按钮。
3. 加号菜单包含剪贴板捕获和文件导入两个入口。
4. 菜单支持再次点击、点击外部和 `Esc` 三种关闭方式。
5. 剪贴板捕获和文件导入继续使用现有流程并展示原有结果。
6. 1100×700 和 1280×800 两种桌面尺寸下没有横向溢出或控件重叠。
7. 来源筛选、搜索、刷新和快速记录行为不受影响。

## 7. 不在本次范围

- AI 延伸或查询能力。
- 新增捕获方式。
- 调整菜单栏和全局快捷键。
- 修改来源分类。
- 重做收集箱整体视觉风格。
