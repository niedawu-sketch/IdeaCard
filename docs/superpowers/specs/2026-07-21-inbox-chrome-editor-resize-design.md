# 收集箱界面精简与原始内容拖拽修复设计

## 1. 目标

降低收集箱左侧 chrome 区的视觉噪音，并恢复卡片详情中“原始内容”编辑器的纵向拖拽能力。

## 2. 范围

本次修改只涉及桌面端收集箱、已归档工作区共用的界面骨架：

- 删除侧栏导航上方的“工作区”辅助标签。
- 删除来源栏标题上方的“统一收集”与“归档内容”辅助标签。
- 删除来源筛选列表上方的“来源”辅助标签。
- 删除侧栏底部的状态点和“本地工作区”文字。
- 删除卡片列表工具栏中的手动刷新按钮。
- 修复卡片详情“原始内容”编辑器右下角缩放手柄被内部滚动条遮挡的问题。
- 收紧删除辅助文字后遗留的垂直间距。

不修改以下内容：

- `IdeaCard` 品牌标识。
- 收集箱、已归档、概念集合等工作区入口及数量。
- 收集箱、已归档主标题。
- 全部来源和五类来源筛选及数量。
- 侧栏折叠与模型设置按钮。
- 首次加载、捕获完成后的自动刷新、加载失败后的重试。
- 快速记录弹窗中的富文本编辑器布局。

## 3. 交互设计

### 3.1 左侧 chrome 精简

删除不参与导航决策的辅助小字。区域的可访问名称继续通过 `aria-label` 或 `aria-labelledby` 提供，不依赖可见标题。

侧栏底部删除状态点和状态文字后，折叠与模型设置按钮靠右排列；分隔线保留，用于区分导航与全局操作。

来源栏删除辅助标题后，主标题作为区域起点；来源筛选列表与主标题之间保留一段清晰但更紧凑的间距。

### 3.2 删除手动刷新

卡片仍在页面首次进入时加载。快速记录、剪贴板捕获、截图和文件导入完成后沿用现有自动更新逻辑。加载失败提示中的“重试”继续调用加载动作，因此移除工具栏刷新按钮不会移除故障恢复入口。

现有依赖刷新按钮触发重新读取磁盘内容的测试改为直接验证公开加载流程或自动更新场景，不在界面中保留仅供测试使用的控件。

### 3.3 原始内容编辑器缩放

根因是外层 `.rich-editor` 负责 `resize: vertical`，内层 `.rich-editor-content` 负责 `overflow-y: auto`；内层滚动条延伸到容器右下角，覆盖外层原生缩放手柄。

详情页改为由同一个 `.rich-editor` 同时负责纵向滚动与纵向缩放，内层编辑区不再创建独立滚动容器。浏览器由此可以统一处理滚动条、滚动条角落和原生缩放手柄，行为与普通可缩放文本框一致。

编辑器继续保持：

- 默认高度 `300px`。
- 最小高度 `200px`。
- 最大高度 `72vh`。
- 只允许纵向缩放。
- 快速记录弹窗不受详情页作用域样式影响。

## 4. 组件与样式变更

- `desktop/src/app/App.tsx`
  - 移除可见“工作区”标签。
  - 移除底部状态点与“本地工作区”文字。
- `desktop/src/pages/InboxPage.tsx`
  - 移除来源栏辅助文案与可见“来源”标题。
  - 移除刷新图标、按钮及对应图标导入。
  - 保留来源区域的可访问名称。
- `desktop/src/shared/styles/global.css`
  - 清理被删除元素的样式。
  - 调整导航、来源筛选和底部操作区间距。
  - 将详情页富文本编辑器改为单层滚动与缩放。
- `desktop/src/pages/InboxPage.test.tsx` 与相关测试
  - 断言辅助小字和刷新按钮不再出现。
  - 保留自动加载、错误重试与编辑器尺寸约束的验证。

## 5. 验收标准

1. 收集箱和已归档界面不再显示“工作区”“统一收集”“归档内容”“来源”“本地工作区”。
2. 侧栏底部不再显示绿色状态点，但折叠和设置按钮仍可使用。
3. 卡片列表工具栏不再显示刷新按钮。
4. 页面首次进入、捕获完成和加载失败重试仍能刷新卡片数据。
5. “原始内容”编辑器有内部滚动内容时，右下角缩放手柄仍可拖动。
6. 拖动后编辑器高度不小于 `200px`、不大于 `72vh`。
7. “我的想法”文本框和快速记录弹窗的编辑器行为不变。
8. 删除辅助文字后不出现明显的空白断层或失去对齐的图标。

## 6. 验证

- 运行桌面端组件测试和静态检查。
- 运行收集箱布局端到端测试。
- 在桌面窗口中手动验证长文本下的滚动与拖拽，覆盖收集箱和已归档只读状态。
