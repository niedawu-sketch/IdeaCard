# 概念名称定位与右键解释浮层实施计划

**日期：** 2026-08-07  
**范围：** 概念解释弹窗的原生名称输入框、原始内容中的已保存概念交互。

## 决策

- 保留概念名称的原生单行输入控件及豆包语音能力，修复流式解释导致的坐标漂移。
- 鼠标悬停概念只改变高亮，不再显示解释。
- 右键已保存概念时，解释以独立浮层显示在文本操作菜单下方，并保留进入概念详情的入口。
- 右键概念不要求用户先手工选择文字。

## 实施步骤

- [x] 让原生普通文本控件响应祖先尺寸变化造成的布局移动。
- [x] 把概念信息提供给全局文本右键菜单，并移除编辑器底部悬停解释层。
- [x] 增加菜单定位、无选区右键、概念详情入口和输入框坐标回归测试。
- [x] 运行前端测试、Lint、构建、Rust 测试和 E2E。
