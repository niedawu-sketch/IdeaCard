# 已保存概念重新解释与覆盖保存实施计划

**日期：** 2026-08-07  
**状态：** 已完成

## 目标

允许用户完整选中一个已保存概念后重新发起 AI 解释，并在明确提示影响范围后覆盖原解释，解决当前保存时报「原文选区已变化」的问题。

## 交互规则

1. 只有完整选中单个既有概念标注，或从该概念的右键菜单发起解释，才进入覆盖模式。
2. 覆盖模式保留原概念名称并设为只读。
3. 解释弹窗显示非阻断警告：保存后会覆盖原解释，所有引用该概念的卡片都会显示新解释。
4. 覆盖模式主按钮显示「覆盖原解释」；不增加二次确认弹窗。
5. 普通选区继续创建新引用；同名复用概念时不覆盖既有解释。

## 实现步骤

1. 让编辑器选区快照携带完整既有标注的概念 ID 与引用 ID。
2. 在卡片详情中识别覆盖目标，并将覆盖状态传入解释弹窗。
3. 扩展保存请求，显式区分新增引用与覆盖既有解释。
4. 覆盖保存时校验既有引用和正文未变化，仅更新概念解释，不新增引用或重写正文。
5. 增加前端交互测试、Rust 仓储测试，并运行完整验证。

## 验收标准

- 已保存概念可重新生成解释并成功覆盖，不再出现选区失效错误。
- 覆盖前能看到影响所有引用的明确提示。
- 覆盖后正文高亮和引用数量不变，所有同一概念引用展示新解释。
- 普通新概念保存与同名概念复用行为不受影响。
