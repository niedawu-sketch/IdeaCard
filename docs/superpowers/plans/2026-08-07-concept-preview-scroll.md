# 概念解释浮层滚动修复计划

**日期：** 2026-08-07  
**状态：** 已完成

## 目标

让较长的概念解释可以在右键浮层内稳定滚动，并把浮层关闭条件收敛到明确的离开操作。

## 实现

1. 移除“任意滚动即关闭”的全局监听。
2. 为解释浮层增加滚动边界，避免滚动穿透到底层卡片。
3. 用浮层背后的透明关闭层承接外部点击，移除 `document` 级外部点击监听。
4. 关闭条件只保留透明层点击和 `Esc`，不响应窗口焦点变化。
5. 增加组件测试和真实浏览器长文本滚动回归。

## 验收

- 滚轮或触控板可以滚动长解释，浮层保持显示。
- 滚到顶部或底部后，底层卡片不跟随滚动。
- 点击浮层外后浮层关闭。

## 实机修订

浏览器回归通过后，macOS WKWebView 实机滚动仍会关闭浮层。剩余关闭入口只有 `window blur`，因此移除窗口失焦关闭，避免滚动过程中的焦点事件误判。

第二次实机仍复现，且拖动滚动条同样关闭。由此确定 `document` 级外部点击命中判断也不可靠：WKWebView 的原生滚动条并非普通 DOM 子节点，交互可能被重新定向到文档。改为独立透明关闭层后，浮层内部不再经过任何全局关闭判断。
