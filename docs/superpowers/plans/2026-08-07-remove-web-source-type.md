# 移除「网页文章」来源类型实施计划

**日期：** 2026-08-07  
**范围：** 用户可见来源分类与网址剪贴自动分类；不修改数据库结构。

## 决策

- 用户界面只保留「个人记录、文档资料」。
- 新捕获的 HTTP/HTTPS 网址归入「文档资料」。
- 历史 `web` 数据继续可读，并在筛选、详情和捕获信息中显示为「文档资料」。
- 底层枚举和数据库约束保留 `web`，避免数据迁移和旧卡片损坏。
