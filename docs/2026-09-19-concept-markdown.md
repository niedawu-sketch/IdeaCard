# 概念解释 Markdown 渲染修复

## 设计

概念解释弹窗、概念集合详情和正文右键预览目前把解释作为纯文本展示，导致 Markdown 标记直接可见。统一复用 AI 延伸已有的 AiMarkdown，不修改解释原文、已保存概念或用户提示词。流式内容按增量重新渲染，保存继续使用原始 Markdown。外部链接沿用应用安全打开接口。

## 实现计划

1. 三处解释正文替换为共享 Markdown 组件并连接外部链接动作。
2. 移除解释容器内纯文本段落样式的干扰，保留紧凑预览字号与原有滚动区域。
3. 验证 Markdown 结构、保存原文、链接和既有概念交互，运行测试、构建和界面检查。

## 验证结果

前端 196 项测试、4 项概念相关浏览器端到端测试、前端构建、ESLint 和差异检查通过。已检查解释弹窗截图，标题、粗体和列表正常显示；测试确认保存仍保留原始 Markdown，HTML 不执行，链接走外部打开接口。开发版已热更新。
